### Task 7: Basic Sales Summary from SQLite Using Python ###

## 📌 Objective
The goal of this task was to connect Python with a simple SQLite database and extract basic sales summaries using SQL. The results were displayed using print statements and a basic bar chart.

## 🛠 Tools Used
- Python
- SQLite3 (built-in to Python)
- Pandas
- Matplotlib

## 📂 Files Included
- `task7_script.py` — Python script to connect to database, run SQL query, and generate a chart
- `sales_data.db` — SQLite database containing sample sales data
- `sales_chart.png` — Bar chart showing revenue per product
- `README.md` — This file

## 🔍 What the Script Does
- Connects to the SQLite database (`sales_data.db`)
- Runs a SQL query to get total quantity and total revenue by product
- Loads the results into a pandas DataFrame
- Prints the results
- Plots a bar chart showing revenue by product using Matplotlib

## 🧠 Learning Outcomes
- Writing basic SQL queries in Python
- Using pandas to manage and analyze SQL query results
- Visualizing simple sales data
- Understanding integration of SQL and Python in data analysis workflows
